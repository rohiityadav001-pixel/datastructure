Data Structure

way of organizing, storing, and managing data

Definition

A Data Structure is a systematic way of organizing, storing, and managing data in a computer’s memory so that the data can be used efficiently. It defines how different pieces of data are related to each other and how operations such as insertion, deletion, searching, sorting, and updating can be performed.

Data structures are important because choosing the right structure can make a program faster, easier to understand, and more efficient in memory usage. Different applications require different types of data structures.

Type of Data Structure

Linear Data Structure

Elements are arranged in a sequence. eg. Array, Linked List, Stack, Queue

Non-Linear Data Structure

Elements are not stored sequentially. eg. Tree and Graph
