1. Introduction to Stacks

A stack is a linear data structure that follows the Last In, First Out (LIFO) principle. The last element inserted is the first one removed.

Insertion and deletion both take place at one end, called the top.

Program: Basic Stack Concept (C)
#include <stdio.h>

int main(void) {
    int stack[3] = {10, 20, 30};
    int top = 2;

    printf("Top element: %d\\n", stack[top]);
    return 0;
}
Output: Top element: 30

💡 Key Points

  • Follows LIFO (Last In, First Out).
  • Push adds an item to the top.
  • Pop removes the top item.
  • Peek reads the top without removing it.
  • Also known as a pushdown stack.
TOP ↓
30
20
10
30 was inserted last, so it comes out first.

2. Memory Representation

A stack can be implemented using an array or a linked list. In an array implementation, a variable called top stores the index of the top element.

Array Representation

TOP = 3 ↓
40
30
20
10
Array indexes: 0, 1, 2, 3 (bottom to top)

Linked-List Representation

TOP →
40 → NULL
↓
30 → next
↓
20 → next
↓
10 → NULL
Array stack: fixed capacity in a basic array implementation.   Linked-list stack: grows dynamically as nodes are allocated.
⚙

3. Applications of Stacks

Stacks are useful when the most recent action or item must be handled first.

Function Calls

Stores function-call information.

Undo / Redo

Tracks recent editing actions.

Expression Evaluation

Helps evaluate expressions and manage operators.

Backtracking

Remembers previous states or choices.

★ Real-World Example: Browser Back

As you visit pages, each page can be placed on a history stack. Pressing Back returns to the most recently visited page.

Stack→Page 1→Page 2→Page 3
The most recent page is at the top.

4. Stack Operations

OperationDescription
push()Adds an element to the top.
pop()Removes the top element.
peek()Returns the top element.
isEmpty()Checks whether the stack is empty.
isFull()Checks whether an array stack is full.

Complete C program for push, pop, peek and display.

Stack Operations (C)
#include <stdio.h>
#define MAX 5

int stack[MAX];
int top = -1;

void push(int value) {
    if (top == MAX - 1) {
        printf("Stack Overflow\\n");
        return;
    }
    stack[++top] = value;
}

void pop(void) {
    if (top == -1) {
        printf("Stack Underflow\\n");
        return;
    }
    printf("Popped: %d\\n", stack[top--]);
}

void peek(void) {
    if (top == -1)
        printf("Stack is empty\\n");
    else
        printf("Top: %d\\n", stack[top]);
}

void display(void) {
    if (top == -1) {
        printf("Stack is empty\\n");
        return;
    }
    for (int i = top; i >= 0; i--)
        printf("%d\\n", stack[i]);
}

int main(void) {
    push(10);
    push(20);
    push(30);
    display();
    peek();
    pop();
    display();
    return 0;
}
Output begins: 30, 20, 10 — Top: 30 — Popped: 30

5. Recursion

Recursion is a programming technique in which a function calls itself to solve a smaller version of a problem.

Every recursive function needs a base case to stop the calls. Function calls are managed using the program's call stack.

Remember: A missing or incorrect base case can cause too many recursive calls and exhaust the call stack.
Program: Factorial Using Recursion
#include <stdio.h>

int factorial(int n) {
    if (n <= 1)
        return 1;

    return n * factorial(n - 1);
}

int main(void) {
    int n = 5;
    printf("Factorial = %d\\n", factorial(n));
    return 0;
}
Output: Factorial = 120

6. Stack Using a Linked List

This implementation creates a new node for each push and removes the first node for pop. It does not require a fixed array capacity.

Linked-List Stack (C)
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *top = NULL;

void push(int value) {
    struct Node *node = malloc(sizeof(struct Node));
    if (node == NULL) {
        printf("Memory allocation failed\\n");
        return;
    }
    node->data = value;
    node->next = top;
    top = node;
}

void pop(void) {
    if (top == NULL) {
        printf("Stack Underflow\\n");
        return;
    }
    struct Node *temp = top;
    printf("Popped: %d\\n", temp->data);
    top = top->next;
    free(temp);
}

void display(void) {
    struct Node *current = top;
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
    printf("\\n");
}

int main(void) {
    push(10);
    push(20);
    push(30);
    display();
    pop();
    display();

    while (top != NULL)
        pop();

    return 0;
}
Output: 30 20 10   |   Popped: 30   |   20 10
