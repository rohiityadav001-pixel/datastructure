Introduction to Sorting

Sorting is the process of arranging data in a particular order, usually ascending or descending. It makes searching and processing data easier.

Example: 40, 10, 30, 20 → 10, 20, 30, 40

1. Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. After each pass, the largest unsorted element moves to the end.

Algorithm

  1. Compare adjacent elements.
  2. Swap them if the first is greater than the second.
  3. Repeat for all pairs in each pass.
  4. Stop when the array is sorted or no swaps occur.
START → Compare adjacent elements ↓ Wrong order? → Swap ↓ Complete a pass ↓ Repeat until sorted → END

Time: Best O(n) with optimization; average/worst O(n²).

2. Insertion Sort

Insertion Sort builds a sorted portion one element at a time. Each new element is inserted into its correct position among the already sorted elements.

Algorithm

  1. Start with the second element as the key.
  2. Compare the key with elements on its left.
  3. Shift larger elements one position right.
  4. Insert the key in the correct position.
  5. Repeat until all elements are sorted.
Select a key ↓ Compare with sorted portion ↓ Shift larger elements right ↓ Insert key ↓ Repeat → END

Time: Best O(n); average/worst O(n²).

3. Selection Sort

Selection Sort repeatedly finds the smallest element from the unsorted portion and places it at the beginning of that portion.

Algorithm

  1. Assume the first unsorted element is the minimum.
  2. Compare it with the remaining unsorted elements.
  3. Find the smallest element.
  4. Swap it with the first unsorted element.
  5. Repeat for the remaining elements.
Find minimum in unsorted part ↓ Swap with first unsorted element ↓ Expand sorted portion ↓ Repeat → END

Time: Best, average, and worst O(n²).

4. Merge Sort

Merge Sort uses the divide-and-conquer technique. It divides the array into smaller parts, sorts each part, and merges the sorted parts.

Algorithm

  1. Divide the array into two halves.
  2. Recursively sort both halves.
  3. Merge the two sorted halves.
  4. Continue until the entire array is sorted.
Original array ↓ Divide into two halves ↓ Divide until single elements ↓ Merge in sorted order ↓ Sorted array

Time: Best, average, and worst O(n log n).

Extra space: O(n) for a typical array implementation.

5. Quick Sort

Quick Sort selects a pivot element and partitions the array so that smaller elements go before the pivot and larger elements go after it. It then sorts the partitions recursively.

Algorithm

  1. Select a pivot.
  2. Partition elements around the pivot.
  3. Apply Quick Sort to the left partition.
  4. Apply Quick Sort to the right partition.
  5. Stop when partitions have zero or one element.
Choose pivot ↓ Partition array ↓ Left part | Pivot | Right part ↓ Sort both parts recursively ↓ Sorted array

Time: Best/average O(n log n); worst O(n²).

Extra space: Typically O(log n) average recursion stack; worst O(n).

Searching vs Sorting

Searching locates a specific element in a collection. Sorting arranges elements into a chosen order. Sorting can make some later operations, such as Binary Search, more efficient.
