01. Introduction to Graphs

A graph is a non-linear data structure consisting of vertices and edges.

Vertices

Vertices, also called nodes, represent objects in a graph.

Edges

Edges connect vertices and represent relationships between them.

Directed Graph

Edges have a direction, such as A → B.

Undirected Graph

Edges have no direction, such as A — B.

Weighted Graph

Edges have values such as distance, time or cost.

Applications

Maps, social networks, computer networks and route planning.

       A -------- B
       |          |
       |          |
       C -------- D

Vertices = A, B, C, D
Edges    = AB, AC, BD, CD

02. Memory Representation

Graphs are commonly represented using adjacency matrices or adjacency lists.

Adjacency Matrix

A two-dimensional array. Matrix[i][j] is 1 when an edge connects the vertices, otherwise 0 for this unweighted graph.

    A B C
A   0 1 1
B   1 0 1
C   1 1 0

Adjacency List

Each vertex stores a list of its neighboring vertices.

A → B → C
B → A → C
C → A → B

03. Depth First Search (DFS)

DFS explores one path as deeply as possible before backtracking. It can be implemented using recursion or a stack.

Working

  • Start at a vertex.
  • Mark it visited.
  • Visit an unvisited neighbor.
  • Backtrack when no unvisited neighbor remains.

Applications

  • Finding connected components
  • Cycle detection
  • Maze solving
  • Path exploration
DFS Example:

A → B → D
    ↓
    C

Possible traversal:
A → B → D → C
(Neighbor order determines the output.)

04. Breadth First Search (BFS)

BFS visits all neighboring vertices first and then moves to the next level. It uses a queue.

Working

  • Start at a vertex.
  • Mark it visited and enqueue it.
  • Remove a vertex from the queue.
  • Enqueue each unvisited neighbor.

Applications

  • Shortest paths in unweighted graphs
  • Social network connections
  • Level-by-level exploration
  • Network broadcasting
BFS Example:

       A
      / \
     B   C
     |
     D

Traversal: A → B → C → D
