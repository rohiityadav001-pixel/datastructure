01. Definition of Linked List

A linked list is a linear data structure made up of nodes. Each node contains data and one or more links (pointers) that connect it to other nodes.

Unlike an array, linked-list nodes do not need to occupy consecutive memory locations. Nodes are connected through pointers.

Data: 10Next
→
Data: 20Next
→
Data: 30NULL

Head → First Node → Second Node → Last Node

Important: The head pointer stores the address of the first node. The last node of a standard singly linked list points to NULL.

02. Memory Representation

Each node is stored at a memory location and contains data and pointer fields. The pointer stores the address of another node.

Data: 15Next: 2040
→
Data: 25Next: 3090
→
Data: 35Next: NULL

Illustrative addresses only — actual memory addresses vary.

Node structure in C

C Structure 
struct Node {
    int data;
    struct Node *next;
};

The data field stores the value, while next stores the address of the next node.

03. Types of Linked List

1. Singly Linked List

Each node contains data and a pointer to the next node. Traversal normally takes place in the forward direction.

10Next
→
20Next

30NULL

2. Doubly Linked List

Each node has three fields: previous pointer, data and next pointer. It supports forward and backward traversal.

NULL ←
Prev | 10Next
⇄
Prev | 20Next
→ NULL

3. Header Linked List

A special header node appears at the beginning. It may store information such as the list length or a pointer to the first data node.

HeaderNext

4. Circular Linked List

The last node points back to the first node instead of NULL. It may be singly circular or doubly circular.

10Next
→
20Next
→
30Next

The final node links back to the first node.

04. Traversing a Linked List

Traversing means visiting each node one by one, starting from the head pointer, until the end of the list is reached.

Algorithm: Start at head → process current node → move to next → repeat until current becomes NULL.

05. Searching in a Linked List

Searching means finding whether a particular value exists in the linked list. Each node is checked sequentially until the value is found or the list ends.

Time complexity: \(O(n)\) in the worst case.

06. Insertion Operations

At the Beginning

Make the new node point to the current head, then update head to the new node.

New Node → Old Head → ...

At the End

Traverse to the last node and make its next pointer point to the new node.

... → Last Node → New Node → NULL

At a Given Position

Reach the node before the required position and adjust the links to include the new node.

Previous → New Node → Next

07. Deletion Operations

Delete First Node

Store the current head temporarily, move head to head's next node and free the old first node.

Delete Last Node

Find the second-last node, set its next pointer to NULL and free the last node.

Delete by Value or Position

Find the target node, connect its previous node to its next node and free the target node.

Always check for an empty list and handle the case where the first node is the one being deleted.

08. Operations on Singly Linked List

A singly linked list supports traversal, searching, insertion and deletion using a single next pointer in every node.

OperationTypical Time
Traverse / SearchO(n)
Insert at beginningO(1)
Insert at end (without tail pointer)O(n)
Delete first nodeO(1)
Delete by valueO(n)

09. Operations on Doubly Linked List

A doubly linked list contains both prev and next pointers. When inserting or deleting a node, both links must be updated correctly.

Doubly Linked List Node 
struct DNode {
    int data;
    struct DNode *prev;
    struct DNode *next;
};
Advantages: forward and backward traversal, and easier deletion when the node to remove is already known. Disadvantage: extra memory is required for the previous pointer.

11. Polynomial Manipulation

A polynomial can be represented as a linked list in which each node stores a coefficient, an exponent and a pointer to the next term.

Coeff: 5Exp: 2
→
Coeff: 3Exp: 1
→
Coeff: 2Exp: 0

Represents: 5x² + 3x + 2

C Structure for a Polynomial Term

Polynomial Node 
struct Poly {
    int coeff;
    int exp;
    struct Poly *next;
};

Adding Two Polynomials

Compare the exponents of the terms in both lists. If the exponents match, add their coefficients. Otherwise, copy the term with the larger exponent into the result. Continue until both lists are processed.

Example: (3x² + 2x + 1) + (4x² + 5x + 6) = 7x² + 7x + 7.

Program 1: Create and Display a Singly Linked List

Singly Linked List 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

int main(void) {
    struct Node *head = NULL, *tail = NULL, *newNode, *temp;
    int n, i, value;

    printf("Enter number of nodes: ");
    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        newNode = malloc(sizeof(struct Node));
        if (newNode == NULL) {
            printf("Memory allocation failed.\n");
            return 1;
        }

        printf("Enter value: ");
        scanf("%d", &value);

        newNode->data = value;
        newNode->next = NULL;

        if (head == NULL) {
            head = tail = newNode;
        } else {
            tail->next = newNode;
            tail = newNode;
        }
    }

    printf("Linked List: ");
    temp = head;
    while (temp != NULL) {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }
    printf("NULL\n");

    while (head != NULL) {
        temp = head;
        head = head->next;
        free(temp);
    }

    return 0;
}
Example Output: Enter number of nodes: 3 Enter value: 10 Enter value: 20 Enter value: 30 Linked List: 10 -> 20 -> 30 -> NULL

Program 2: Search for a Value

Linked List Search 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

int main(void) {
    struct Node *head = NULL, *tail = NULL, *node, *temp;
    int n, i, value, key, position = 1;

    printf("Enter number of nodes: ");
    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        node = malloc(sizeof(struct Node));
        if (node == NULL) return 1;

        printf("Enter value: ");
        scanf("%d", &value);

        node->data = value;
        node->next = NULL;

        if (head == NULL) head = tail = node;
        else {
            tail->next = node;
            tail = node;
        }
    }

    printf("Enter value to search: ");
    scanf("%d", &key);

    temp = head;
    while (temp != NULL && temp->data != key) {
        temp = temp->next;
        position++;
    }

    if (temp != NULL)
        printf("Value found at position %d\n", position);
    else
        printf("Value not found\n");

    while (head != NULL) {
        temp = head;
        head = head->next;
        free(temp);
    }

    return 0;
}
Example Output: Enter number of nodes: 3 Enter value: 10 Enter value: 20 Enter value: 30 Enter value to search: 20 Value found at position 2

Program 4: Delete the First Node

Deletion 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

int main(void) {
    struct Node *head, *second, *temp;

    head = malloc(sizeof(struct Node));
    second = malloc(sizeof(struct Node));

    if (head == NULL || second == NULL) {
        free(head);
        free(second);
        return 1;
    }

    head->data = 10;
    head->next = second;
    second->data = 20;
    second->next = NULL;

    printf("Before deletion: ");
    for (temp = head; temp != NULL; temp = temp->next)
        printf("%d -> ", temp->data);
    printf("NULL\n");

    temp = head;
    head = head->next;
    free(temp);

    printf("After deletion: ");
    for (temp = head; temp != NULL; temp = temp->next)
        printf("%d -> ", temp->data);
    printf("NULL\n");

    free(head);
    return 0;
}
Example Output: Before deletion: 10 -> 20 -> NULL After deletion: 20 -> NULL

Program 5: Doubly Linked List Traversal

Doubly Linked List 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *prev;
    struct Node *next;
};

int main(void) {
    struct Node *first, *second, *third, *temp;

    first = malloc(sizeof(struct Node));
    second = malloc(sizeof(struct Node));
    third = malloc(sizeof(struct Node));

    if (first == NULL || second == NULL || third == NULL) {
        free(first);
        free(second);
        free(third);
        return 1;
    }

    first->data = 10;
    first->prev = NULL;
    first->next = second;

    second->data = 20;
    second->prev = first;
    second->next = third;

    third->data = 30;
    third->prev = second;
    third->next = NULL;

    printf("Forward: ");
    for (temp = first; temp != NULL; temp = temp->next)
        printf("%d ", temp->data);

    printf("\nBackward: ");
    for (temp = third; temp != NULL; temp = temp->prev)
        printf("%d ", temp->data);

    printf("\n");

    free(first);
    free(second);
    free(third);

    return 0;
}
Example Output: Forward: 10 20 30 Backward: 30 20 10

Program 6: Add Two Polynomials

Polynomial Addition 
#include <stdio.h>
#include <stdlib.h>

struct Poly {
    int coeff, exp;
    struct Poly *next;
};

void append(struct Poly **head, int coeff, int exp) {
    struct Poly *node = malloc(sizeof(struct Poly));
    struct Poly *temp;

    if (node == NULL) {
        printf("Memory allocation failed.\n");
        exit(1);
    }

    node->coeff = coeff;
    node->exp = exp;
    node->next = NULL;

    if (*head == NULL) {
        *head = node;
        return;
    }

    temp = *head;
    while (temp->next != NULL)
        temp = temp->next;

    temp->next = node;
}

void display(struct Poly *p) {
    int first = 1;

    while (p != NULL) {
        if (!first) printf(" + ");
        printf("%dx^%d", p->coeff, p->exp);
        first = 0;
        p = p->next;
    }
    printf("\n");
}

int main(void) {
    struct Poly *a = NULL, *b = NULL, *result = NULL;
    struct Poly *p, *q;
    int n, m, c, e, i;

    printf("Number of terms in first polynomial: ");
    scanf("%d", &n);
    printf("Enter each coefficient and exponent in descending exponent order:\n");

    for (i = 0; i < n; i++) {
        scanf("%d%d", &c, &e);
        append(&a, c, e);
    }

    printf("Number of terms in second polynomial: ");
    scanf("%d", &m);
    printf("Enter each coefficient and exponent in descending exponent order:\n");

    for (i = 0; i < m; i++) {
        scanf("%d%d", &c, &e);
        append(&b, c, e);
    }

    p = a;
    q = b;

    while (p != NULL && q != NULL) {
        if (p->exp == q->exp) {
            c = p->coeff + q->coeff;
            if (c != 0) append(&result, c, p->exp);
            p = p->next;
            q = q->next;
        } else if (p->exp > q->exp) {
            append(&result, p->coeff, p->exp);
            p = p->next;
        } else {
            append(&result, q->coeff, q->exp);
            q = q->next;
        }
    }

    while (p != NULL) {
        append(&result, p->coeff, p->exp);
        p = p->next;
    }

    while (q != NULL) {
        append(&result, q->coeff, q->exp);
        q = q->next;
    }

    printf("Sum: ");
    if (result == NULL) printf("0\n");
    else display(result);

    while (a != NULL) {
        p = a; a = a->next; free(p);
    }
    while (b != NULL) {
        p = b; b = b->next; free(p);
    }
    while (result != NULL) {
        p = result; result = result->next; free(p);
    }

    return 0;
}
Example Input: First polynomial terms: 2 3 2 2 1 Second polynomial terms: 2 4 2 5 0 Example Output: Sum: 7x^2 + 2x^1 + 5x^0
