01. Tree: Definition & Basic Concepts

A tree is a non-linear data structure that organizes data in a hierarchical manner using nodes and edges.

Root

The topmost node of a tree. It has no parent.

Parent & Child

A parent is a node connected to nodes below it. Those nodes are its children.

Leaf Node

A node that has no children.

Edge

A connection between two nodes.

Depth & Level

Depth counts edges from the root. Level numbering depends on the convention used.

Subtree

A node together with all its descendants forms a subtree.

02. Representation in Contiguous Storage

A binary tree can be stored in an array, with parent and child positions calculated using indices.

Array Representation

For a zero-based array at index i:

  • Left child = 2i + 1
  • Right child = 2i + 2
  • Parent = floor((i − 1) / 2)

Advantages

Simple indexing, fast parent-child access and no pointer storage needed.

Limitations

Sparse or irregular trees may waste array space. Linked representation is often more flexible.

          A                Array index
         / \               0: A
        B   C              1: B    2: C
       / \                 3: D    4: E
      D   E

Array: [A, B, C, D, E]

For index 1 (B):
Left child  = 2(1) + 1 = 3  → D
Right child = 2(1) + 2 = 4  → E

03. Binary Tree

A binary tree is a tree in which each node has at most two children: a left child and a right child.

Full Binary Tree

Every node has either zero or exactly two children.

Complete Binary Tree

All levels are full except possibly the last, which fills from left to right.

Perfect Binary Tree

All internal nodes have two children and all leaves are at the same depth.

Skewed Binary Tree

Each node has at most one child, producing a left- or right-skewed shape.

05. Searching, Insertion & Deletion

These operations help locate nodes, add new nodes and remove existing nodes. Their exact procedure depends on the type of binary tree.

Searching

Visit nodes until the required value is found. In a general binary tree, a search may need to examine every node.

Insertion

In a general binary tree, insertion follows the chosen structural rule. In a BST, compare values to find the correct position.

Deletion

Remove a node while preserving the tree's required structure and, for a BST, its ordering property.

Deletion in a BST — three cases
  1. Leaf node: remove it directly.
  2. One child: connect its parent to its child.
  3. Two children: replace it with its inorder successor or predecessor, then remove that replacement node from its original position.

06. Binary Search Tree (BST)

A BST is a binary tree organized by a comparison rule.

BST Property

For each node, values in the left subtree are smaller and values in the right subtree are larger. This example uses distinct values.

            50
           /  \
         30    70
        / \    / \
       20 40  60 80

Inorder: 20, 30, 40, 50, 60, 70, 80

Advantages

  • Supports efficient searching when balanced.
  • Inorder traversal produces sorted values.
  • Supports insertion and deletion.

Time Complexity

  • Search: O(log n) average in a balanced BST.
  • Insert: O(log n) average in a balanced BST.
  • Worst case: O(n) in a skewed BST.

BST Search Algorithm

SEARCH(root, key)

1. If root is NULL:
      Return NOT FOUND

2. If key equals root.data:
      Return FOUND

3. If key is less than root.data:
      Search root.left

4. Otherwise:
      Search root.right
