Introduction to Searching

Searching is the process of finding a particular element, called a key, in a list or array. It helps determine whether the element exists and, if found, its position.

Types of Searching

  • Linear Search: Checks elements one by one.
  • Binary Search: Repeatedly divides a sorted array into halves.

1. Linear Search

Linear Search compares the key with each element, starting from the first element. It stops when the key is found or the list ends.

Algorithm

  1. Start from the first element.
  2. Compare the current element with the key.
  3. If equal, return its position.
  4. Otherwise, move to the next element.
  5. If all elements are checked, report that the key was not found.

Example

Array: 12, 25, 7, 40, 18

Key: 40

Comparisons: 12 → 25 → 7 → 40

Result: Found at position 4 (index 3).

START ↓ Read array and key ↓ Check each element ↓ Element equals key? ├── YES → Display position → END └── NO → Check next element ↓ List finished? ├── YES → Not found → END └── NO → Repeat

2. Binary Search

Binary Search finds an element by repeatedly dividing the search range into two halves. The array must be sorted before using this method.

Algorithm

  1. Set low = 0 and high = n - 1.
  2. Calculate mid = low + (high - low) / 2.
  3. If the middle element equals the key, return its position.
  4. If the key is smaller, search the left half.
  5. If the key is larger, search the right half.
  6. Repeat until found or low > high.

Example

Sorted array: 10, 20, 30, 40, 50, 60, 70

Key: 60

Middle = 40 → search right half.

Middle = 60 → element found at position 6 (index 5).

START ↓ Set low = 0, high = n - 1 ↓ Is low ≤ high? ├── NO → Not found → END └── YES → Calculate mid ↓ Compare key with A[mid] ├── Equal → Found → END ├── Smaller → high = mid - 1 └── Larger → low = mid + 1 ↓ Repeat
