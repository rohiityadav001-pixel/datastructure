01. Introduction to Queue

A queue is a linear data structure in which insertion takes place at one end called the REAR, and deletion takes place at the other end called the FRONT.

A queue follows the FIFO (First In, First Out) principle. The element inserted first is removed first.

Example: People standing in a ticket line. The person who arrives first generally gets served first.

02. Basic Queue Operations

Enqueue

Adds a new element at the rear end of the queue.

Dequeue

Removes an element from the front end of the queue.

Peek / Front

Returns the front element without removing it.

isEmpty

Checks whether the queue contains any elements.

isFull

Checks whether an array-based queue has reached its capacity.

Overflow: Attempting to insert into a full fixed-size queue.
Underflow: Attempting to remove an element from an empty queue.

04. Types of Queue

1. Linear Queue

Elements are inserted at the rear and removed from the front. In a simple array implementation, unused spaces at the beginning may not be reused without shifting elements.

2. Circular Queue

The last array position connects logically to the first position. Freed spaces can be reused by wrapping around.

3. Priority Queue

Elements are processed according to priority. Elements with higher priority are served first, depending on the implementation.

4. Double-Ended Queue

A deque allows insertion and deletion at both the front and rear ends.

05. Linear Queue

A linear queue follows the FIFO rule. In a common array implementation, front starts at -1 and rear starts at -1. When the first element is inserted, both become 0.

07. Priority Queue

A priority queue stores elements with priorities. The element selected for removal depends on its priority rather than solely on its arrival time.

Element Priority
A3
B1
C2

If a smaller number represents higher priority, B is processed first, followed by C and then A.

08. Double-Ended Queue (Deque)

A deque, pronounced “deck”, is a queue in which insertion and deletion are possible at both ends.

Input-Restricted Deque

Insertion is allowed at one end, while deletion is allowed at both ends.

Output-Restricted Deque

Deletion is allowed at one end, while insertion is allowed at both ends.

09. Applications of Queue

CPU Scheduling

Processes can wait in a queue for CPU time.

Printer Queue

Print jobs wait to be processed by a printer.

Breadth-First Search

Queues help visit graph or tree vertices level by level.

Network Data

Packets can wait in queues before transmission.

Customer Service

Requests can be handled in arrival order.

Buffers

Queues help manage data between devices or processes operating at different speeds.

10. C Programs

Program 1: Queue Using Array

Linear Queue 
#include <stdio.h>
#define SIZE 5

int queue[SIZE];
int front = -1, rear = -1;

void enqueue(int value) {
    if (rear == SIZE - 1) {
        printf("Queue Overflow\n");
        return;
    }

    if (front == -1)
        front = 0;

    queue[++rear] = value;
    printf("%d inserted\n", value);
}

void dequeue(void) {
    if (front == -1 || front > rear) {
        printf("Queue Underflow\n");
        return;
    }

    printf("Deleted: %d\n", queue[front++]);

    if (front > rear)
        front = rear = -1;
}

void display(void) {
    int i;

    if (front == -1) {
        printf("Queue is empty\n");
        return;
    }

    printf("Queue: ");
    for (i = front; i <= rear; i++)
        printf("%d ", queue[i]);

    printf("\n");
}

int main(void) {
    enqueue(10);
    enqueue(20);
    enqueue(30);

    display();
    dequeue();
    display();

    return 0;
}

Program 2: Circular Queue Using Array

Circular Queue 
#include <stdio.h>
#define SIZE 5

int queue[SIZE];
int front = -1, rear = -1;

void enqueue(int value) {
    if ((rear + 1) % SIZE == front) {
        printf("Queue is full\n");
        return;
    }

    if (front == -1)
        front = 0;

    rear = (rear + 1) % SIZE;
    queue[rear] = value;
}

void dequeue(void) {
    if (front == -1) {
        printf("Queue is empty\n");
        return;
    }

    printf("Deleted: %d\n", queue[front]);

    if (front == rear) {
        front = rear = -1;
    } else {
        front = (front + 1) % SIZE;
    }
}

void display(void) {
    int i;

    if (front == -1) {
        printf("Queue is empty\n");
        return;
    }

    printf("Queue: ");
    i = front;

    while (1) {
        printf("%d ", queue[i]);

        if (i == rear)
            break;

        i = (i + 1) % SIZE;
    }

    printf("\n");
}

int main(void) {
    enqueue(10);
    enqueue(20);
    enqueue(30);
    enqueue(40);

    display();
    dequeue();
    enqueue(50);
    enqueue(60);
    display();

    return 0;
}
