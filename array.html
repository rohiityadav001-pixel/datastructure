01. Introduction to Arrays

An array is a linear data structure that stores multiple elements of the same data type in contiguous memory locations. Each element is accessed using an index.

Syntax:

data_type array_name[size];

Example: int marks[5];

Array indexing in C starts from 0.

Program: Declare and Display an Array 
#include <stdio.h>

int main() {
    int a[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        printf("%d ", a[i]);
    }

    return 0;
}
Output:

10 20 30 40 50

02. Types of Arrays

Arrays are commonly classified according to their dimensions.

01. One-Dimensional Array

Stores elements in a single sequence.

int a[5];

02. Two-Dimensional Array

Stores elements in rows and columns.

int a[3][3];

03. Multidimensional Array

Stores data using three or more dimensions.

int a[2][3][4];

04. Character Array

Stores characters and can represent strings.

char name[20];

Program: Two-Dimensional Array 
#include <stdio.h>

int main() {
    int a[2][2] = {{1, 2}, {3, 4}};

    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            printf("%d ", a[i][j]);
        }
        printf("\n");
    }

    return 0;
}
Output:

1 2

3 4

03. Memory Representation

Array elements are stored in contiguous memory locations. The address of each element depends on its index and size.

Example: int a[4] = {10, 20, 30, 40};

Index 0 10 1000
Index 1 20 1004
Index 2 30 1008
Index 3 40 1012

Illustration assumes a 4-byte integer and a starting address of 1000. Actual addresses vary by system.

Address Formula (1D Array)

LOC(A[i]) = Base Address + i × Element Size

For example, LOC(A[2]) = 1000 + 2 × 4 = 1008.

Row-Major Representation of a 2D Array

In C, a two-dimensional array is stored row by row.

Program: Display Array Addresses 
#include <stdio.h>

int main() {
    int a[3] = {10, 20, 30};

    for (int i = 0; i < 3; i++) {
        printf("a[%d] = %d, Address = %p\n",
               i, a[i], (void *)&a[i]);
    }

    return 0;
}

Column-Major Representation of a 2D Array

In column-major representation, elements of a two-dimensional array are stored column by column in consecutive memory locations. This is commonly used in languages such as Fortran. C uses row-major representation by default.

Example: A[2][3]

A[0][0] 10 1000
A[1][0] 40 1004
A[0][1] 20 1008
A[1][1] 50 1012
A[0][2] 30 1016
A[1][2] 60 1020
Column-Major Address Formula

LOC(A[i][j]) = Base Address + (j × Number of Rows + i) × Element Size

Example: LOC(A[1][1]) = 1000 + (1 × 2 + 1) × 4 = 1012.

Program: Simulate Column-Major Storage 
#include <stdio.h>

int main() {
    int a[2][3] = {
        {10, 20, 30},
        {40, 50, 60}
    };

    int rows = 2, cols = 3;

    printf("Column-Major Order:\n");

    for (int j = 0; j < cols; j++) {
        for (int i = 0; i < rows; i++) {
            printf("%d ", a[i][j]);
        }
    }

    return 0;
}
Output:

10 40 20 50 30 60

Time Complexity: O(rows × cols)

Note: This C program simulates the column-major traversal order. The actual two-dimensional array is still stored in row-major order in C.

05. Array Traversal

Traversal means visiting each element of an array one by one.

C Program: Traversal 
#include <stdio.h>

int main() {
    int a[] = {5, 10, 15, 20, 25};
    int n = 5;

    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }

    return 0;
}
Output:

5 10 15 20 25

Time Complexity: O(n)

06. Array Insertion

Insertion adds a new element at a specified position. Existing elements may need to be shifted to the right.

C Program: Insert an Element 
#include <stdio.h>

int main() {
    int a[10] = {10, 20, 30, 40};
    int n = 4, pos = 2, value = 25;

    if (n < 10 && pos >= 0 && pos <= n) {
        for (int i = n; i > pos; i--) {
            a[i] = a[i - 1];
        }

        a[pos] = value;
        n++;

        for (int i = 0; i < n; i++) {
            printf("%d ", a[i]);
        }
    } else {
        printf("Invalid position or full array");
    }

    return 0;
}
Output:

10 20 25 30 40

Time Complexity: O(n)

Note: Position is zero-based, so position 2 inserts the element as the third element.

07. Array Deletion

Deletion removes an element from a specified position. The following elements shift one place to the left.

C Program: Delete an Element 
#include <stdio.h>

int main() {
    int a[5] = {10, 20, 30, 40, 50};
    int n = 5, pos = 2;

    if (pos >= 0 && pos < n) {
        for (int i = pos; i < n - 1; i++) {
            a[i] = a[i + 1];
        }

        n--;

        for (int i = 0; i < n; i++) {
            printf("%d ", a[i]);
        }
    } else {
        printf("Invalid position");
    }

    return 0;
}
Output:

10 20 40 50

Time Complexity: O(n)

08. Searching in an Array

Linear search checks each element until the required value is found or the array ends.

C Program: Linear Search 
#include <stdio.h>

int main() {
    int a[] = {10, 20, 30, 40, 50};
    int n = 5, key = 30, found = 0;

    for (int i = 0; i < n; i++) {
        if (a[i] == key) {
            printf("Element found at index %d", i);
            found = 1;
            break;
        }
    }

    if (!found) {
        printf("Element not found");
    }

    return 0;
}
Output:

Element found at index 2

Time Complexity: O(n)

09. Sorting an Array

Sorting arranges array elements in ascending or descending order. Bubble sort compares adjacent elements and swaps them when they are in the wrong order.

C Program: Bubble Sort 
#include <stdio.h>

int main() {
    int a[] = {40, 10, 30, 20, 50};
    int n = 5, temp;

    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }

    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }

    return 0;
}
Output:

10 20 30 40 50

Time Complexity: O(n²) in the average and worst cases.

10. Advantages & Limitations

Advantages

  • Fast access using an index.
  • Simple to understand and implement.
  • Stores multiple values under one name.
  • Useful for searching and sorting.

Limitations

  • Fixed size for ordinary C arrays.
  • Insertion and deletion may require shifting.
  • Elements normally share one data type.
  • Resizing can require creating another array.
Conclusion

Arrays are one of the fundamental data structures. They provide efficient indexed access and are widely used in searching, sorting, matrices and the implementation of other data structures.
