Introduction to Complexity

Algorithm complexity describes the resources an algorithm needs as the input size grows. The two main measures are time complexity (number of operations) and space complexity (extra memory used).

Time Complexity

Estimates how the number of steps grows with input size n.

Example: Checking every element in an array takes O(n) time.

Space Complexity

Estimates the memory required while the algorithm runs.

Example: A loop using only a few variables usually uses O(1) auxiliary space.

C program: Linear search

This program checks each array element until the key is found or the array ends. Its worst-case time complexity is O(n).

#include <stdio.h>

int main(void) {
    int a[] = {12, 7, 25, 9, 18};
    int n = 5, key = 9, i, found = 0;

    for (i = 0; i < n; i++) {
        if (a[i] == key) {
            printf("Found at index %d\\n", i);
            found = 1;
            break;
        }
    }

    if (!found)
        printf("Not found\\n");

    return 0;
}
Remember: Big-O notation describes an upper bound on growth; it helps compare algorithms as input becomes large.

C program: Store and display data in an array

#include <stdio.h>

int main(void) {
    int marks[5] = {75, 82, 68, 91, 77};
    int i;

    for (i = 0; i < 5; i++) {
        printf("%d ", marks[i]);
    }

    return 0;
}

Output: 75 82 68 91 77

03

Data Structure Operations

Operations are actions performed on stored data. The most common operations are:

Traversal

Visit each element to display or process it.

Insertion

Add a new element at a required position.

Deletion

Remove an element from the structure.

Searching

Find an element with a given value.

Sorting

Arrange elements in ascending or descending order.

Merging

Combine two similar structures into one.

C program: Insert an element at a position

Positions in this example start at 1. The array must have enough capacity, and the chosen position must be valid.

#include <stdio.h>

int main(void) {
    int a[10] = {10, 20, 30, 40};
    int n = 4, pos = 3, value = 25, i;

    if (n >= 10 || pos < 1 || pos > n + 1) {
        printf("Invalid insertion\\n");
        return 0;
    }

    for (i = n; i >= pos; i--) {
        a[i] = a[i - 1];
    }
    a[pos - 1] = value;
    n++;

    for (i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }

    return 0;
}

Output: 10 20 25 30 40

Insertion or deletion in the middle of an array may require shifting elements, so it can take O(n) time.
04

Applications of Data Structures

Data structures are used in software to organize information and make common tasks easier and faster.

Operating Systems

Queues schedule processes; trees and lists help manage system information.

Databases

B-trees and hash tables support indexing and fast record lookup.

Web Browsers

Stacks can support back/forward history and undo-style actions.

Maps and Networks

Graphs model roads, routes, social connections and computer networks.

Compilers

Trees represent expressions and program syntax; symbol tables track names.

Messaging and Scheduling

Queues help process tasks in arrival order.

A queue is useful when tasks should be processed in first-in, first-out order (FIFO).

C program: Simple queue using an array

#include <stdio.h>
#define SIZE 5

int main(void) {
    int queue[SIZE];
    int front = 0, rear = -1, i;

    /* Enqueue three items */
    queue[++rear] = 10;
    queue[++rear] = 20;
    queue[++rear] = 30;

    /* Display from front to rear */
    printf("Queue: ");
    for (i = front; i <= rear; i++) {
        printf("%d ", queue[i]);
    }

    /* Dequeue one item */
    printf("\\nRemoved: %d\\n", queue[front]);
    front++;

    return 0;
}

Output: Queue: 10 20 30, then Removed: 10.

C program: Stack using an array

#include <stdio.h>
#define SIZE 5

int main(void) {
    int stack[SIZE], top = -1;

    /* Push two values */
    if (top < SIZE - 1) stack[++top] = 10;
    if (top < SIZE - 1) stack[++top] = 20;

    printf("Top element: %d\\n", stack[top]);

    /* Pop one value */
    if (top >= 0) {
        printf("Popped: %d\\n", stack[top--]);
    }

    return 0;
}

Output: Top element: 20 and Popped: 20.
